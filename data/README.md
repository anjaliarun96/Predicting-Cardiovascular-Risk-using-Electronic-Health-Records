# Dataset

This project uses the public Kaggle **Cardiovascular Disease dataset** (70,000 patient records).

1. Download it from Kaggle: search "Cardiovascular Disease dataset" (author: sulianova). A free Kaggle account is needed.
2. Unzip and place the file here as `data/cardio_train.csv` (semicolon-separated, columns:
   `id;age;gender;height;weight;ap_hi;ap_lo;cholesterol;gluc;smoke;alco;active;cardio`).

The CSV is git-ignored so the repo stays small.
